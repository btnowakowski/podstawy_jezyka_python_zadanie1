# zad2 - małe programy

11 krótkich programów z konsoli, wybieranych z menu.

```sh
cd source
uv run python -m zad2.main
```

## Ćwiczenia

| # | Ćwiczenie | Gdzie |
|---|-----------|-------|
| 1 | Konwersja temperatur °C na °F | `numbers.temperature` |
| 2 | Liczba parzysta czy nieparzysta | `numbers.even_or_odd` |
| 3 | Kalkulator wieku (obsługa roku z przyszłości) | `numbers.age` |
| 4 | Generator powitania | `text.greeting` |
| 5 | Liczenie znaków bez spacji | `text.count_chars` |
| 6 | Średnia trzech ocen | `numbers.average` |
| 7 | Sprawdzanie hasła (min. 8 znaków i cyfra) | `text.check_password` |
| 8 | Porównywanie dwóch liczb | `numbers.compare_numbers` |
| 9 | Mnożenie tekstu | `text.repeat_word` |
| 10 | Test „Ile to 2 + 2?” | `text.quiz` |
| 11 | Prosty kalkulator | `numbers.calculator` |

## Pliki

- `main.py` - menu
- `numbers.py` - ćwiczenia na liczbach (1, 2, 3, 6, 8, 11)
- `text.py` - ćwiczenia na tekście (4, 5, 7, 9, 10)
