# zad3 - warunki

5 zadań z konsoli, wybieranych z menu.

```sh
cd source
uv run python -m zad3.main
```

## Zadania

| # | Zadanie | Gdzie |
|---|---------|-------|
| 1 | Trzy liczby: największa, najmniejsza, średnia, czy suma jest parzysta (bez `max()` i `min()`) | `numbers.three_numbers` |
| 2 | Czas filmu w godzinach i minutach, krótki czy długi film | `everyday.film_duration` |
| 3 | Czy z trzech boków da się zbudować trójkąt i jaki to trójkąt | `triangle.check_triangle` |
| 4 | Silnia ze sprawdzaniem danych | `numbers.factorial_with_checks` |
| 5 | Wypłata z nadgodzinami i podatkiem 19% | `everyday.payday` |

## Pliki

- `main.py` - menu
- `numbers.py` - zadania 1 i 4
- `triangle.py` - zadanie 3
- `everyday.py` - zadania 2 i 5
